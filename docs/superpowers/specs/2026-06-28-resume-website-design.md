# 赵英琦个人简历网站 — 设计文档

> 现代化、响应式、简约工科风个人简历单页网站

## 目标

为零依赖的单一 HTML 文件，保存即用，完整展示赵英琦的嵌入式/机器人工程方向个人简历信息。

## 技术栈

- HTML5 + CSS3 + 原生 JavaScript
- 零外部依赖（无 CDN、无框架）
- 响应式设计（桌面端 960px 居中 + 移动端自适应折叠）

## 配色体系

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 — 科技蓝 | `#1a6fc4` | 标题、关键词高亮、分割线、链接 |
| 辅色 — 深灰 | `#2d3436` | 正文文字 |
| 背景 — 浅灰 | `#f5f6fa` | 页面底色 |
| 卡片白 | `#ffffff` | 模块卡片背景 |
| 标签底色 | `#e8f0fe` | 课程/技能标签背景 |
| 代码注释绿 | `#6a9955` | 技术装饰元素 |

## 排版字体

- 中文：系统默认（`PingFang SC, Microsoft YaHei, sans-serif`）
- 代码装饰：`Consolas, Monaco, monospace`

## 页面结构（从上到下）

### 1. Header — 头部横幅

- 左侧圆形头像（120px，支持替换照片路径，默认 `assets/photo.jpg`）
- 姓名：28px 粗体科技蓝
- 副标题：`嵌入式开发 · 机器人工程`，深灰色
- 联系方式横条：电话/邮箱/地址，带 Unicode 图标前缀
- 底部代码注释装饰：`// aspiring embedded engineer`
- 移动端：头像上移居中，联系方式换行

### 2. 教育经历

- 左侧蓝色竖线 `3px` 装饰
- 校名 + 专业 + GPA（科技蓝高亮）同一行
- 就读时间灰色小字
- 主修课程：圆角标签网格排列，浅蓝底色

### 3. 技能证书

- 分类展示：
  - 🔧 嵌入式硬件（重点）：芯片型号/工具名标签网格
  - 🌐 语言证书：单行紧凑
  - 📋 办公技能：单行紧凑
  - 🚗 通用证书：单行紧凑
- 嵌入式标签使用深色边框科技蓝强调

### 4. 竞赛荣誉

- 奖牌图标（🥉🥈）前缀
- 竞赛名称 + 奖项 + 时间，简洁条目

### 5. 项目经历（重点区块）

- 每个项目独立卡片，内部轻微阴影
- 项目名使用 📁 文件图标前缀
- 核心技术关键词**自动加粗并着色科技蓝**：
  STM32、MSPM0、PID、OpenMV、Python、Keil5、CubeMX、IIC、USART、SPI、C51
- 角色 + 时间灰色副标题

### 6. 自我评价

- 纯文字区块，行距 1.8 舒适阅读
- 左侧蓝色竖线与其他模块统一

### 7. Footer — 底部收尾

- C 语言多行注释风格：`/* 2026 · 赵英琦 · embedded & robotics */`
- 代码注释绿色，等宽字体，居中

## 响应式策略

| 断点 | 布局调整 |
|------|---------|
| > 768px | 960px 居中，全宽卡片 |
| ≤ 768px | 全宽，头像居中，联系方式纵向排列，标签网格1-2列 |
| ≤ 480px | 字号微缩，标签单列，卡片内边距收紧 |

## 技术装饰

- 模块标题：左侧 `3px solid #1a6fc4` 竖线
- 顶部：`// single-line comment` 绿色代码装饰
- 底部：`/* multi-line comment */` 绿色代码装饰
- 关键词：`<code>` 风格高亮，monospace + 科技蓝

## 头像处理

- 用户提供真实照片，路径建议 `assets/photo.jpg`
- 若照片缺失，降级为 CSS 绘制的字母头像（"赵" 字圆形）

## 浏览器兼容

- Chrome / Firefox / Safari / Edge 近两年版本
- 移动端 iOS Safari / Android Chrome
